# yt-autopilot

**A personal, single-user desktop command-line tool.**

yt-autopilot runs locally on its author's own Windows PC and manages the author's own
YouTube channel. It produces videos from public statistical data, then uses the YouTube
Data API v3 and the YouTube Analytics API to set metadata, thumbnails and scheduled
publish times on those videos, and to read the channel's own performance data.

It is **not a service**. It is not distributed, it is not installed by anyone else, and it has
no users other than its author. There is no sign-up, no account, and no mechanism to
authenticate any account other than the author's own.

## What it does

1. Produces video and thumbnail files locally from public statistical sources, using
   free text-to-speech, stock footage and generated diagrams.
2. Uploads or annotates the author's own videos on the author's own channel, as private
   with a scheduled publish time.
3. Reads the author's own channel analytics to decide what to produce next.
