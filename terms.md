## 2. Permitted use

Only the author may use this tool, and only with the author's own YouTube channel. The tool contains no facility for authenticating any other account.

## 3. What the tool does

1. Uploads video files that the author produced, to the author's own channel, as private with a scheduled publish time.
2. Sets metadata (title, description, tags, category, language, made-for-kids declaration, thumbnail, scheduled publish time) on the author's own videos.
3. Reads the author's own channel's analytics.

## 4. What the tool does not do

- It does not use browser automation or any means of accessing YouTube other than the official API.
- It does not circumvent, disable, or interfere with any part of the YouTube service.
- It does not store YouTube API data beyond what is described in the Privacy Policy.
